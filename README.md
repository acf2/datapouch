# Datapouch
Constructor of interactive CLI CRUD applications via asdf system-based plugins, written in Common Lisp, that transforms SBCL into the app. Focus on: programmability, simplicity, preserving SBCL functionality as far as could be achieved (by yours truly).

Caveats:
1. Programmability and simplicity are not that compatible. There are several choices in design, that seemingly contradict one or both of these focal points. E.g.: usage of regexes, instead of simple reader-macros; all the fuss with a way that regexes/expressions/patterns are constructed; handling of interactivity in command macros; and many others. I cannot really defend this, as my design choices sometimes look insane even to me. But usually I had put some thought into it, and have tried more than one approach.
2. Programmability *really* limits accessibility/reach of this app. This is fine. The only way to use it, for user that does not know programming, is to use my premade plugins. They should not be interested in it anyway, because, quote: 'All software had been already written. No new ideas are worth pursuing by your own. Just use something.' So, *just use something else*, as many normal, sane people advocate.
3. Some parts of it are made from shit and sticks. Like application package. I will try to document how to work with such parts, but unless I had written the whole thing and started fixing bugs/bad design choices, this is a pie in the sky. It will be unstable, it will be infuriatingly illogical at times. Price of dealing with eldritch tech, which had been meddled with by an amateur, I guess.
